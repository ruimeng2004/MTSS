# BTMS混合指标技术分析报告

**问题**: 为什么不同权重配置产生相同的路由结果

## 🔍 根本原因确认

### 问题：置信度缩放机制失效

**核心问题**: HybridMetric的最终调整公式使用了过大的缩放因子，导致所有ratio都被拉向0.5。

```python
# 代码位置: budget_metrics.py, HybridMetric.compute()
final_ratio = 0.5 + (weighted_ratio - 0.5) * overall_confidence
```

这个公式的设计意图是：当置信度低时，ratio应该偏向保守的0.5（50-50分配）。但实际执行中，**所有cluster的置信度都极低**，导致所有ratio都坍缩到0.5附近。

## 🎯 根本问题

### 问题1: PPL置信度缩放因子过大

```python
ppl_conf = min(abs(gap) / 10.0, 1.0)
```

**问题**:
- 假设gap在0-10范围，但实际gap平均仅0.017
- 缩放因子应该根据实际数据分布调整
- 建议缩放因子应为0.1-0.5，而非10.0

**影响**:
- PPL置信度平均仅0.0017，最大0.014
- PPL组件几乎完全失效

### 问题2: Vote置信度定义不合理

```python
vote_conf = min(avg_gap / 0.5, 1.0)
```

**问题**:
- 使用平均gap作为置信度，但gap本身就很小
- 阈值0.5与实际数据不匹配
- Vote置信度平均也仅0.042

### 问题3: 最终调整公式过度保守

```python
final_ratio = 0.5 + (weighted_ratio - 0.5) * overall_confidence
```

**问题**:
- 这个公式假设低置信度时应该回归0.5
- 但由于置信度定义问题，**ALL** cluster被判定为低置信度
- 导致所有ratio都被拉回0.5
- 失去了区分不同cluster的能力

### 问题4: 缺乏数据驱动的参数调整

**当前硬编码的参数**:
- PPL缩放因子: 10.0
- Vote阈值: 0.5
- Size归一化: 10

**问题**:
- 这些参数没有基于实际PPL数据分布
- 导致所有置信度都极低
- 需要数据驱动的参数选择

## 🔧 建议的修复方案

### 短期方案：调整缩放参数

1. **重新校准PPL置信度**
   ```python
   # 当前
   ppl_conf = min(abs(gap) / 10.0, 1.0)
   
   # 建议（基于实际数据分布：mean=0.017, max=0.14）
   ppl_conf = min(abs(gap) / 0.15, 1.0)  # 最大gap为0.14，用0.15为上限
   ```

2. **重新校准Vote置信度**
   ```python
   # 当前
   vote_conf = min(avg_gap / 0.5, 1.0)
   
   # 建议（基于实际数据）
   vote_conf = min(avg_gap / 0.05, 1.0)  # 调整为更合理的阈值
   ```

3. **移除或减弱最终调整**
   ```python
   # 选项A: 移除置信度缩放
   final_ratio = weighted_ratio
   
   # 选项B: 使用平方根减弱影响
   confidence_factor = math.sqrt(overall_confidence)
   final_ratio = 0.5 + (weighted_ratio - 0.5) * confidence_factor
   
   # 选项C: 使用最小置信度阈值
   adjusted_conf = max(overall_confidence, 0.3)  # 最低30%
   final_ratio = 0.5 + (weighted_ratio - 0.5) * adjusted_conf
   ```

### 中期方案：数据驱动的参数选择

1. **自动校准缩放因子**
   ```python
   # 基于数据分布自动设置
   gap_95th_percentile = compute_percentile(all_gaps, 0.95)
   ppl_scaling_factor = gap_95th_percentile
   ```

2. **归一化到[0,1]**
   ```python
   # 使用min-max归一化
   normalized_gap = (gap - min_gap) / (max_gap - min_gap)
   ppl_conf = normalized_gap
   ```

### 长期方案：重新设计置信度机制

1. **分离置信度和权重**
   - 不要用置信度压制ratio
   - 置信度只用于标记不确定性，不影响决策

2. **使用贝叶斯方法**
   - 先验分布：均匀分布[0, 1]
   - 后验更新基于PPL证据强度

3. **机器学习方法**
   - 训练模型预测最优ratio
   - 使用实际修复成功率作为监督信号
