# D4J Fix Evaluation System

A comprehensive system for evaluating Defects4J bug fixes generated by AI models.

## Features

- **Automated Evaluation**: Automatically applies patches and runs tests
- **Multiple Formats**: Supports both Edit (SEARCH/REPLACE) and Rewrite formats
- **Patch Normalization**: Converts patches to unified diff format
- **Detailed Reporting**: Generates comprehensive evaluation reports
- **Parallel Processing**: Support for parallel bug evaluation (coming soon)

## Installation

```bash
# Install dependencies
pip install -r requirements.txt

# Verify setup
python -m evaluation.verify_setup
```

## Quick Start

### Basic Usage

```bash
# Evaluate all bugs in a result folder
python -m evaluation --result-folder ppl/result/20260105_132306

# Specify output directory
python -m evaluation \
    --result-folder ppl/result/20260105_132306 \
    --output evaluation_output
```

### Advanced Usage

```bash
# Evaluate specific bugs only
python -m evaluation \
    --result-folder ppl/result/20260105_132306 \
    --bugs Chart_1,Chart_2,Closure_10

# Enable verbose logging
python -m evaluation \
    --result-folder ppl/result/20260105_132306 \
    --verbose

# Use custom configuration
python -m evaluation \
    --result-folder ppl/result/20260105_132306 \
    --config custom_config.yaml

# Save logs to file
python -m evaluation \
    --result-folder ppl/result/20260105_132306 \
    --log-file evaluation.log

# Parallel evaluation (not yet implemented)
python -m evaluation \
    --result-folder ppl/result/20260105_132306 \
    --workers 4
```

## Command-Line Options

| Option | Description | Default |
|--------|-------------|---------|
| `--result-folder` | Path to result folder (required) | - |
| `--output` | Output directory for results | `./evaluation_output` |
| `--workers` | Number of parallel workers | `1` |
| `--verbose` | Enable verbose logging | `False` |
| `--config` | Path to configuration file | `config.yaml` |
| `--bugs` | Comma-separated list of bugs to evaluate | All bugs |
| `--log-file` | Path to log file | Console only |

## Input Format

The result folder should have the following structure:

```
result_folder/
├── Chart_1/
│   ├── 1/
│   │   ├── model_output.txt
│   │   ├── query.txt
│   │   └── result.json
│   ├── 2/
│   │   ├── model_output.txt
│   │   ├── query.txt
│   │   └── result.json
│   └── ...
├── Chart_2/
│   └── ...
└── ...
```

### Model Output Formats

#### Edit Format (SEARCH/REPLACE)

```
###public void methodName()
<<<<<<< SEARCH
old code
=======
new code
>>>>>>> REPLACE
```

#### Rewrite Format

```
###public void methodName()
```java
complete new method code
```
```

## Output

The evaluation system generates:

1. **Normalized Patches**: Unified diff format patches in `patches/`
2. **Bug Results**: Individual bug evaluation results in `bug_results/`
3. **Batch Result**: Overall evaluation summary in `batch_result.json`
4. **Statistics**: Detailed statistics in `statistics.json`
5. **Logs**: Execution logs in `evaluation.log`

### Example Output Structure

```
evaluation_output/
├── patches/
│   ├── Chart_1_1.patch
│   ├── Chart_1_2.patch
│   └── ...
├── bug_results/
│   ├── Chart_1.json
│   ├── Chart_2.json
│   └── ...
├── batch_result.json
├── statistics.json
└── evaluation.log
```

## Configuration

### Quick Setup

1. Copy the example configuration:
```bash
cp evaluation/config.example.yaml config.yaml
```

2. Edit `config.yaml` and update the `d4j_path`:
```yaml
evaluation_config:
  d4j_path: "/path/to/your/defects4j"  # Update this!
```

3. Validate your configuration:
```bash
python -m evaluation.validate_config
```

### Configuration File

Create a `config.yaml` file with the following structure:

```yaml
evaluation_config:
  # Defects4J installation path (required)
  d4j_path: "/path/to/defects4j"
  
  # Workspace directory for bug checkouts
  workspace_dir: "./workspace"
  
  # Output directory for results
  output_dir: "./evaluation_output"
  
  # Test execution timeout (seconds)
  timeout: 600
  
  # Number of parallel workers
  parallel_workers: 4
  
  # Enable result caching
  cache_enabled: true
  
  # Deprecated bugs to skip
  deprecated_bugs:
    - "Lang_2"
    - "Lang_18"
    # ... more bugs
  
  # Normalization settings
  normalization:
    context_lines: 3
    max_retries: 3
  
  # Logging settings
  logging:
    level: "INFO"
    file: "evaluation.log"
    format: "%(asctime)s - %(name)s - %(levelname)s - %(message)s"
```

### Configuration Validation

Validate your configuration before running evaluation:

```bash
# Validate configuration file
python -m evaluation.validate_config

# This will check:
# - Configuration file syntax
# - Required fields
# - D4J installation
# - Directory paths
```

### Configuration Options

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `d4j_path` | string | required | Path to Defects4J installation |
| `workspace_dir` | string | `./workspace` | Directory for bug checkouts |
| `output_dir` | string | `./evaluation_output` | Directory for results |
| `timeout` | int | `600` | Test timeout in seconds |
| `parallel_workers` | int | `4` | Number of parallel workers |
| `cache_enabled` | bool | `true` | Enable result caching |
| `deprecated_bugs` | list | `[]` | List of bugs to skip |
| `normalization.context_lines` | int | `3` | Context lines in diffs |
| `normalization.max_retries` | int | `3` | Max patch application retries |
| `logging.level` | string | `INFO` | Log level |
| `logging.file` | string | `evaluation.log` | Log file path |

## Exit Codes

- `0`: Success (at least one bug fixed)
- `1`: Failure (no bugs fixed or error occurred)
- `130`: Interrupted by user (Ctrl+C)

## Troubleshooting

### Common Issues

1. **"Result folder does not exist"**
   - Check that the path is correct
   - Use absolute path if relative path doesn't work

2. **"Config file does not exist"**
   - Ensure `config.yaml` exists in the current directory
   - Or specify path with `--config`

3. **"D4J environment not found"**
   - Install Defects4J and set `D4J_HOME` environment variable
   - Or specify path in `config.yaml`

4. **"Checkout failed"**
   - Ensure you have Java 11, Perl, SVN, and Git installed
   - Check Defects4J installation with `defects4j info`
