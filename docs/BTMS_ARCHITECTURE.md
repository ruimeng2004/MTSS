## 四种预算分配指标对比

```
┌──────────────────┬─────────────────────────────────────────────────┐
│   指标           │              计算逻辑                           │
├──────────────────┼─────────────────────────────────────────────────┤
│ PPL Gap          │ gap = avg(edit_ppl) - avg(gen_ppl)             │
│                  │ ratio = sigmoid(-gap / temperature)             │
│                  │ 优点: 连续平滑                                   │
│                  │ 缺点: 忽略投票和簇大小                           │
├──────────────────┼─────────────────────────────────────────────────┤
│ Vote Consistency │ base = edit_votes / total                       │
│                  │ conf = min(avg_gap / threshold, 1.0)            │
│                  │ ratio = 0.5 + (base - 0.5) * conf               │
│                  │ 优点: 结合投票和PPL强度                          │
│                  │ 缺点: 不考虑簇大小                               │
├──────────────────┼─────────────────────────────────────────────────┤
│ Size Adjusted    │ vote_ratio = edit_votes / total                 │
│                  │ size_factor = min(size / norm, 1.0)             │
│                  │ ratio = 0.5 + (vote_ratio - 0.5) * size_factor  │
│                  │ 优点: 考虑簇大小可靠性                           │
│                  │ 缺点: 只用投票，忽略PPL强度                      │
├──────────────────┼─────────────────────────────────────────────────┤
│ Hybrid ⭐         │ 加权组合所有三个信号:                            │
│ (推荐)           │ • PPL Gap 信号 (权重: 0.4)                      │
│                  │ • 投票信号 (权重: 0.4)                          │
│                  │ • 大小信号 (权重: 0.2)                          │
│                  │ 优点: 综合所有优势，最鲁棒                       │
│                  │ 缺点: 参数较多                                   │
└──────────────────┴─────────────────────────────────────────────────┘
```

## 决策流程图（以 Hybrid 指标为例）

```
开始
 │
 ├─> 收集代表点的 PPL 分数
 │   • edit_ppls = [15.5, 18.2, 12.8]
 │   • gen_ppls = [20.3, 16.1, 22.5]
 │
 ├─> 计算 PPL Gap 组件
 │   • gap = mean(edit_ppls) - mean(gen_ppls)
 │   • ppl_ratio = sigmoid(-gap / T)
 │   • ppl_conf = min(|gap| / 10, 1.0)
 │
 ├─> 计算投票组件
 │   • edit_votes = count(e < g)
 │   • vote_ratio = edit_votes / total
 │   • vote_conf = min(avg(gaps) / threshold, 1.0)
 │
 ├─> 计算大小组件
 │   • size_factor = min(cluster_size / norm, 1.0)
 │
 ├─> 综合置信度
 │   • overall_conf = ppl_conf*w1 + vote_conf*w2 + size_factor*w3
 │
 ├─> 加权比例
 │   • weighted_ratio = ppl_ratio*w1 + vote_ratio*(w2+w3)
 │
 ├─> 应用置信度调整
 │   • final_ratio = 0.5 + (weighted_ratio - 0.5) * overall_conf
 │
 ├─> 边界约束
 │   • edit_ratio = clamp(final_ratio, min_ratio, max_ratio)
 │   • gen_ratio = 1.0 - edit_ratio
 │
 ├─> 确定决策
 │   • if |edit_ratio - 0.5| < 0.05: decision = "mixed"
 │   • elif edit_ratio > 0.5: decision = "edit"
 │   • else: decision = "gen"
 │
 └─> 输出结果
     • decision: "edit"
     • ratio: {"edit": 0.65, "gen": 0.35}
     • confidence: 0.78
```

## 配置层次结构

```yaml
btms_config.yaml
├─ selector_type              # 选择器类型
│  ├─ binary                  # 二元选择
│  └─ budget_allocator        # 预算分配
│
├─ binary_selector            # 二元选择器配置
│  ├─ voting_strategy         # 投票策略
│  └─ default_choice          # 默认选择
│
├─ budget_allocator           # 预算分配器配置
│  ├─ metric                  # 指标选择
│  │  ├─ ppl_gap
│  │  ├─ vote_consistency
│  │  ├─ size_adjusted
│  │  └─ hybrid ⭐
│  ├─ min_ratio               # 最小比例
│  ├─ max_ratio               # 最大比例
│  └─ metric_params           # 指标参数
│     ├─ temperature
│     ├─ confidence_threshold
│     ├─ size_normalization_factor
│     └─ [weights for hybrid]
│
├─ adaptive_reps              # 自适应代表点
│  ├─ enabled
│  ├─ divisor
│  ├─ max_reps
│  └─ min_reps
│
└─ outlier_detection          # 异常值检测
   ├─ enabled
   ├─ threshold
   ├─ merge_strategy
   └─ similarity
      ├─ threshold
      └─ linkage
```

## 使用场景

```
┌────────────────────────────────────────────────────────────┐
│ 场景 1: 快速原型 (Binary Selector)                        │
├────────────────────────────────────────────────────────────┤
│ 配置: selector_type = "binary"                             │
│ 输出: decision = "edit" 或 "gen"                           │
│ 适用: 快速测试、简单场景                                   │
└────────────────────────────────────────────────────────────┘

┌────────────────────────────────────────────────────────────┐
│ 场景 2: 精细控制 (Budget Allocator + PPL Gap)            │
├────────────────────────────────────────────────────────────┤
│ 配置: metric = "ppl_gap"                                   │
│ 输出: ratio = {"edit": 0.65, "gen": 0.35}                 │
│ 适用: 需要根据模型偏好强度分配资源                         │
└────────────────────────────────────────────────────────────┘

┌────────────────────────────────────────────────────────────┐
│ 场景 3: 生产环境 (Budget Allocator + Hybrid) ⭐           │
├────────────────────────────────────────────────────────────┤
│ 配置: metric = "hybrid" + adaptive_reps + outlier_handler │
│ 输出: ratio + confidence + 自适应采样                      │
│ 适用: 最鲁棒、最全面的配置，推荐用于生产                   │
└────────────────────────────────────────────────────────────┘
```
