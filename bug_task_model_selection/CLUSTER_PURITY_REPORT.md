# 聚类纯度分析报告 (Edit vs Gen)

本报告分析了不同配置下聚类的纯度，即每个簇中 edit 和 gen 任务的比例分布。

## 配置概览

- **基础模型**: qwen3_30b, qwen3_coder
- **视图**: buggy_code, buggy_code_mixed, buggy_code_obfuscated, error, error_plus_test, report, test
- **K 值范围**: 10 - 500

## 指标说明

- **平均纯度**: 所有簇纯度的算术平均值
- **加权纯度**: 按簇大小加权的平均纯度
- **纯度**: max(edit_count, gen_count) / total_count
- **误分类数**: 所有簇中少数派任务的总数（被分到错误簇的样本数）
- **误分类率**: 误分类数 / 总样本数（1 - 加权纯度）
- **平均Edit比例**: 所有簇中 edit 任务的平均比例
- **平均簇大小**: 每个簇的平均样本数

## 关键发现

### 1. K 值与纯度/误分类率的关系

- 随着 K 值增加，平均纯度显著提升，误分类率显著下降
- K=500 时，大多数配置的平均纯度达到 0.94-0.97，误分类率降至 0.10-0.13
- K=100 时，误分类率约为 0.33-0.36（约 230-250 个样本被误分类）
- 加权纯度的提升幅度更大，表明大簇的纯度改善明显

### 2. 视图对比

- **error** 视图在两个模型上都表现最好，误分类率最低
- **buggy_code_obfuscated** 视图也显示出较高的纯度
- **report** 视图的纯度相对较低，误分类率较高

### 3. 模型对比

- qwen3_coder 在大多数配置下略优于 qwen3_30b
- 两个模型的差异较小（误分类率差异通常在 0.01-0.03 范围内）
- 在 error 视图上，qwen3_coder 的优势更明显

### 4. 误分类分析

- 在 K=100 时，约有 33-36% 的样本被分配到少数派任务簇中
- 误分类率 = 1 - 加权纯度，直接反映聚类质量
- 较小的 K 值（如 K=10）误分类率可达 42-47%
- 增加 K 值是降低误分类率的有效方法
