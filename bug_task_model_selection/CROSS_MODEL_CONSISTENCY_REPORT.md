# 跨模型一致性分析报告

**分析日期**: 2026-01-17  
**数据集**: 698 个 bugs  
**模型**: qwen3_coder vs qwen3_30b  
**研究问题**: 基础模型改变时，bug 的任务建模偏好是否也改变？

---

## 核心发现

### **整体一致性: 58.9%**

- **一致的 bugs**: 411 个 (58.9%)
- **不一致的 bugs**: 287 个 (41.1%)

**结论**: **任务建模选择具有显著的模型依赖性**。超过 40% 的 bugs 在不同基础模型上的最优任务建模不同。

---

## 1. 整体一致性分析

### 1.1 偏好分布对比

| 模型 | Edit 偏好 | Gen 偏好 | 偏好倾向 |
|------|-----------|----------|----------|
| qwen3_coder | 310 (44.4%) | 388 (55.6%) | 偏好 Gen |
| qwen3_30b | 365 (52.3%) | 333 (47.7%) | 偏好 Edit |

**发现**: 两个模型的整体偏好相反
- qwen3_coder 更适合 Gen 策略（55.6%）
- qwen3_30b 更适合 Edit 策略（52.3%）

### 1.2 偏好转移矩阵

从 qwen3_coder 到 qwen3_30b 的偏好变化:

| coder → 30b | Edit | Gen | 总计 | 稳定性 |
|-------------|------|-----|------|--------|
| **Edit** | 194 | 116 | 310 | **62.6%** |
| **Gen** | 171 | 217 | 388 | **55.9%** |
| **总计** | 365 | 333 | 698 | - |

**发现**:
- **Edit 偏好更稳定**: 62.6% 的 Edit bugs 在两个模型上都是 Edit
- **Gen 偏好较不稳定**: 只有 55.9% 的 Gen bugs 在两个模型上都是 Gen
- **37.4%** 的 coder-Edit bugs 在 30b 上变成了 Gen
- **44.1%** 的 coder-Gen bugs 在 30b 上变成了 Edit

---

## 2. 按差距大小分析一致性

### 2.1 一致性与差距的关系

| 差距类别 | 相对差距范围 | 一致数 | 不一致数 | 总数 | 一致率 |
|---------|-------------|--------|----------|------|--------|
| negligible | < 5% | 12 | 10 | 22 | **54.5%** |
| small | 5-20% | 23 | 19 | 42 | **54.8%** |
| medium | 20-50% | 35 | 33 | 68 | **51.5%** |
| large | 50-100% | 46 | 43 | 89 | **51.7%** |
| huge | ≥ 100% | 295 | 182 | 477 | **61.8%** |

### 2.2 关键发现

1. **差距大的 bugs 一致性更高**
   - 差距 ≥ 100%: 一致率 61.8%
   - 差距 < 5%: 一致率 54.5%
   - 提升: +7.3%

2. **但提升有限**
   - 即使差距巨大（≥100%），仍有 38.2% 不一致
   - 说明模型依赖性很强，不仅仅是差距小的 bugs 受影响

3. **中等差距最不稳定**
   - 差距 20-100% 的 bugs 一致率最低（51.5-51.7%）
   - 这些 bugs 对模型最敏感

---

## 3. 高敏感 bugs 分析

### 3.1 定义

**高敏感 bugs**: 两个模型的差距都 ≥ 100%

### 3.2 统计

- **总数**: 241 个
- **一致**: 170 个 (70.5%)
- **不一致**: 71 个 (29.5%)

### 3.3 关键发现

**即使两个模型都认为任务建模选择很重要（差距都 ≥ 100%），仍有 29.5% 的 bugs 在两个模型上的最优选择不同。**

这说明：
- 任务建模的最优选择不仅取决于 bug 本身
- 还强烈依赖于基础模型的特性
- 不能简单地认为"差距大就稳定"

---

## 5. 实际影响分析

### 5.1 跨模型应用的风险

**场景**: 使用 qwen3_coder 的任务建模选择结果，应用到 qwen3_30b

**结果**:
- **41.1%** 的 bugs 会选择错误的任务建模
- 相当于 **287 个 bugs** 的性能会受损

### 5.2 性能损失估算

假设：
- 正确选择: 使用最优策略
- 错误选择: 使用次优策略

对于不一致的 287 个 bugs:
- 在 qwen3_coder 上选对，在 qwen3_30b 上选错
- 平均差距 269.5%，意味着显著的性能损失

### 5.3 最坏情况

以 Csv_6 为例:
- qwen3_coder: Gen 最优（差距 1135361.1%）
- qwen3_30b: Edit 最优（差距 2260.0%）

如果用 coder 的选择（Gen）应用到 30b:
- 会选择 Gen，但 Edit 才是最优
- 性能损失 2260.0%

## 6. 结论与建议

### 6.1 主要结论

1. **任务建模选择具有显著的模型依赖性**
   - 整体一致性仅 58.9%
   - 超过 40% 的 bugs 在不同模型上的最优选择不同

2. **差距大不等于稳定**
   - 即使差距 ≥ 100%，仍有 38.2% 不一致
   - 高敏感 bugs 也有 29.5% 不一致

3. **模型偏好存在系统性差异**
   - qwen3_coder 偏好 Gen (55.6%)
   - qwen3_30b 偏好 Edit (52.3%)

4. **不一致的 bugs 差距仍然很大**
   - 中位数差距 63-170%
   - 说明选择错误会导致显著性能损失

### 6.2 实用建议

#### 建议 1: 为每个模型单独选择（推荐）

**方法**: 为每个基础模型单独运行任务建模选择

**优点**:
- 保证每个模型都使用最优策略
- 避免 41.1% 的选择错误

**缺点**:
- 需要为每个模型计算 PPL
- 增加计算成本

#### 建议 2: 使用保守策略

**方法**: 对于不一致风险高的 bugs，使用默认策略

**识别高风险 bugs**:
- 差距 < 100% 的 bugs（一致率仅 51-55%）
- 或使用模型集成预测一致性

**优点**:
- 减少错误选择的风险
- 降低计算成本

**缺点**:
- 可能错过一些优化机会

#### 建议 3: 模型集成

**方法**: 使用多个模型的投票结果

**实现**:
```python
if coder_pref == b30_pref:
    # 两个模型一致，使用该选择
    strategy = coder_pref
else:
    # 两个模型不一致，使用默认策略或进一步分析
    strategy = "default"  # 或基于其他特征决定
```

**优点**:
- 利用多个模型的信息
- 对一致的 bugs 有信心

**缺点**:
- 需要多个模型的 PPL
- 对不一致的 bugs 仍需决策

### 6.3 未来研究方向

1. **预测一致性**
   - 研究哪些 bug 特征导致模型间不一致
   - 建立一致性预测模型

2. **理解模型差异**
   - 分析为什么不同模型对同一 bug 有不同偏好
   - 研究模型架构、训练数据的影响

3. **自适应策略**
   - 根据 bug 特征和模型特性动态选择
   - 开发模型无关的任务建模选择方法
